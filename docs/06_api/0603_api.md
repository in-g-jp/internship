# 0603 APIを作ろう

## ルーティング
Laravelの「ルーティング」とは、ユーザーからのURLリクエストを正しいプログラム（コントローラー）へ振り分ける「案内所」の仕組みです。

会社の電話応対に例えると、URL（外線電話）が入った際に、ルーティング（受付）がルールブックに従って担当部署へ処理をバトンタッチするイメージです。この案内ルールは、プロジェクト内の routes/web.php というファイルにまとめて記述します。

先ず、sailを起動しましょう。
```
sail up 
```
続いて、エディターでroutes/web.phpを開き、以下のプログラム(+されている行)を追記してください。
```diff
<?php

use Illuminate\Support\Facades\Route;

Route::get('/', function () {
    return view('welcome');
});

+Route::get('/greeting', function () {
+    return 'Hello World';
+});
```
次のURLの開き、'Hello World'と記載されていれば成功です。
http://localhost/greeting

## APIルーティング
プロジェクト内にあるroutesディレクトリ内に'api.php'というファイルを作成してください。
ファイル内に以下のコードを記載してください。
```
<?php

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Route;

Route::get('/greeting', function (Request $request) {
    return response([
        'message' => 'Hello world!'
    ]);
});

```
次に、bootstrapディレクトリ内で、app.phpファイルを開きます。
以下で追記されている通りに、app.phpに'api: ~'と追記しましょう。
```diff
<?php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
+       api: __DIR__.'/../routes/api.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    ->withMiddleware(function (Middleware $middleware): void {
        //
    })
    ->withExceptions(function (Exceptions $exceptions): void {
        //
    })->create();
```
反映しましょう。
次のURLを開き、'{"message":"Hello world!"}'と表示されていれば成功です。
http://localhost/api/greeting

## 作るもの

クエリパラメータで都道府県名を渡すと、その県庁所在地を返す API を作ります。

**リクエスト例**
```
GET /api/capital?prefecture=東京都
```

**レスポンス例**
```json
{
    "prefecture": "東京都",
    "capital": "東京"
}
```

---

## リクエスト / レスポンス

**成功時 200**

```json
{
    "prefecture": "東京都",
    "capital": "東京"
}
```

**都道府県が見つからない場合 404**

```json
{
    "message": "該当する都道府県が見つかりません。"
}
```

**パラメータなしの場合 400**

```json
{
    "message": "prefecture パラメータは必須です。"
}
```

## 学習

### 今何をしたか

クエリパラメータを受け取り、対応するデータを返す GET API を作成しました。

| 用語 | 説明 |
|------|------|
| クエリパラメータ | URL の `?` 以降に付与するパラメータ（例: `?prefecture=東京都`） |
| `$request->query()` | クエリパラメータを取得する Laravel のメソッド |
| 400 Bad Request | リクエストの内容が不正なときに返すステータスコード |
| 404 Not Found | 該当するリソースが存在しないときに返すステータスコード |
