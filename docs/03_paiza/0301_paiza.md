# 0301 Paiza への登録・ログイン

## Paiza とは

Paiza はブラウザ上でプログラミングの問題を解きながらスキルを磨けるサービスです。
実務に近い問題が多く、コーディング力を高めるのに最適です。

---

## 1. アカウント登録

[https://paiza.io](https://paiza.io) にアクセスし、以下の手順で登録してください。

1. 右上の「新規登録」をクリック
2. メールアドレス・パスワードを入力、または Google / GitHub アカウントで登録
3. 登録後、届いた確認メールのリンクをクリックして認証を完了
4. プログラミング学習のタブを開き、再度、会員登録
